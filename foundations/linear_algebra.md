# Linear algebra

## Dot product

The dot product of two vectors $$\mathbf{a} = [a_1, a_2, \cdots, a_n]$$ and $$\mathbf{b} = [b_1, b_2, \cdots, b_n]$$ is defined as:

$$\begin{align}
\mathbf{a} \cdot \mathbf{b} &:= \sum_{i=1}^{n} a_i b_i \\\\[6pt]
&=\left\|\mathbf{a}\right\| \left\|\mathbf{b}\right\| \cos\theta \quad \text{where } \theta \text{ is the angle between } \mathbf{a} \text{ and } \mathbf{b}
\end{align}$$

> [!NOTE]
> - The dot product is a scalar value that measures the extent to which one vector aligns with another.

## Eigenvector and eigenvalues

Let $$A$$ be a square matrix. A non-zero vector $$\mathbf{v}$$ is an eigenvector of $$A$$ if there exists a scalar $$\lambda$$ (an eigenvalue) such that $$A\mathbf{v} = \lambda \mathbf{v}$$. 

- An eigenvector $$\mathbf{v}$$ preserves its line of action under the linear transformation $$A$$ (it is only scaled).
- An eigenvalue $$\lambda$$ represents the scaling factor of the corresponding eigenvector under the linear transformation $$A$$.

> [!NOTE]
> - A matrix $$A \in \mathbb{K}^{n \times n}$$ has exactly $$n$$ eigenvalues (counted with multiplicity) in $$\mathbb{C}$$, and at most $$n$$ distinct ones.
> - Eigenvalues are the roots of the *characteristic equation* $$\det(A - \lambda I) = 0$$.
> - Diagonalization theorem: $$A \in \mathbb{K}^{n \times n}$$ is diagonalizable if and only if
it has $$n$$ linearly independent eigenvectors (that is, they form a basis of $$\mathbb{K}^{n}$$).

## Trace

The trace of a $$n \times n$$ square matrix $$A$$ is the sum of its diagonal elements.

$$tr(A) := \sum_{i=1}^n a_{ii}$$

## Invertible matrix theorem

Let $$A$$ be a square matrix $$A$$ of size $$n \times n$$, and let $$T:\mathbb{R}^n \rightarrow \mathbb{R}^n$$ be the transformation $$T(x) = Ax$$. The following statements are equivalent:

- **Singularity:** $$A$$ is non-singular.
- **Pivots:** $$A$$ has $$n$$ pivots.
- **Invertibility:** $$A$$ is invertible, that is, there exist a matrix $$B$$ such that $$AB = BA = I$$.
- **Invertibility:** $$T$$ is invertible, that is, $$T^{-1}$$ exists.
- **Bijectivity:** $$T$$ is bijective, that is, both injective (one-to-one) and surjective (onto).
- **Determinant:** The determinant of $$A$$ is non-zero, that is, $$\det(A)\neq 0$$.
- **Linear independence:** The columns of $$A$$ are linearly independent.
- **Span:** The columns of $$A$$ span $$\mathbb{R}^n$$.
- **Null space:** The null space of $$A$$ is trivial, that is, $$\text{null}(A)={0}$$.
- **Rank:** $$A$$ is full rank, that is, $$\text{rank}(A)=n$$.
- **Unicity:** $$Ax=y$$ has a unique solution for $$\forall y \in \mathbb{R}^n$$.

## Linear independence

A set of vectors $$\{\mathbf{v}_1​,\mathbf{v}_2​, \cdots, \mathbf{v}_n​\}$$ is linearly independent if no vector in the set can be expressed as a linear combination of the others.

## Matrix rank

The rank of a matrix $$A$$ is the dimension of the vector space generated by its columns, which also corresponds to the maximum number of columns in $$A$$ that are linearly independent.

> [!TIP]
> The number of linearly independent rows always equals the number of linearly independent columns.

> [!NOTE]
> - **Full-rank:** A matrix has full rank if its rank equals the lesser of the number of rows and columns.
> - **Rank-deficiency:** A matrix is rank-deficient if it does not have full rank. 
> - **Rank-nullity theorem:** The rank of a matrix added to the dimension of its null space is equal to the number of its columns.

> [!IMPORTANT]
> The rank of a matrix is a crucial diagnostic tool for understanding the behavior of a linear system $$A\mathbf{x}=\mathbf{y}$$.
> - **Existence:** The system is said to be *consistent* and has a solution only if the rank of the augmented matrix $$[A \mid \mathbf{y}]$$ is equal to the rank of $$A$$; otherwise it means $\mathbf{y}$ is in a direction that $$A$$ cannot reach.
> - **Uniqueness:** If a matrix has full column rank, the system has at most one solution. Combined with the existence condition, a square full-rank matrix has exactly one solution. Otherwise, if the system is consistent, it has infinitely many solutions.

## Vector norms

| Norm | Name | Mathematical definition | Effect |  ML Application |
| :--- | :--- | :--- | :--- |
| **$$L^0$$** | Zero norm | $$\lVert x\rVert_0 := \text{nnz}\{i: x_i \neq 0\}$$ | **Cardinality**: Count the number of non-zero elements. | Compressed sensing, Best subset selection |
| **$$L^1$$** | Manhattan / Taxicab | $$\lVert x\rVert_1 := \sum \|x_i\|$$ | **Sparsity**: Measure the absolute distance; forces coefficients to zero. | LASSO regression, Feature selection, Sparse autoencoders |
| **$$L^2$$** | Euclidean | $$\lVert x\rVert_2 := \sqrt{\sum x_i^2}$$ | **Magnitude**: Measure the straight-line distance; penalize large values. | Ridge regression, Weight decay, SVM margin maximization |
| **$$L^p$$** | Minkowski | $$\lVert x\rVert_p := \Big(\sum \|x_i\|^p\Big)^{1/p}$$ | **Generalization**: Adjust the sensitivity between sum and max. | K-nearest neighbors, $$L^p$$ regularization |
| **$$L^\infty$$** | Chebyshev | $$\lVert x\rVert_\infty := \max \|x_i\|$$ | **Maximum Error**: Identify only the single largest deviation. | Adversarial robustness, FGSM attacks, Worst-case error bounding |
